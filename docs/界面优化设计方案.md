# SHARE 界面优化设计方案（统一浅色 + 直播侧栏布局）

> 归档说明（2026-11-23）：桌面端已移出主项目并冻结留存，本文涉及桌面端的章节仅作历史记录，不再适用。

> 网页端沿用浅色风（暖灰底）。布局参照 B 站直播间的「左视频 + 右侧固定聊天栏」，弹幕无气泡平铺。

---

## 一、设计令牌

```css
:root {
  /* 背景层级（浅色） */
  --bg-page:    #F5F5F3;   /* 页面底（暖灰） */
  --bg-player:  #0A0A0A;   /* 视频框（黑，画面本身） */
  --bg-panel:   #FFFFFF;   /* 侧栏 / 面板 */
  --bg-elevated:#FFFFFF;   /* 提示卡 */
  --bg-input:   #F5F5F3;   /* 输入框 */
  --bg-hover:   #EDEDEA;   /* hover */

  /* 1px 细线 */
  --line:       #E8E8E5;
  --line-strong:#D8D8D4;

  /* 文字 */
  --text-1: #18181A;   /* 标题 */
  --text-2: #2A2A2C;   /* 正文 */
  --text-3: #6B6B68;   /* 次要 */
  --text-4: #9A9A96;   /* 弱化 */

  /* SHARE 品牌色：紫色（唯一强调色，两端统一） */
  --brand:      #9147FF;
  --brand-hover:#A970FF;
  --brand-soft: rgba(145,71,255,.10);

  /* 语义 */
  --success:#16A34A;
  --danger: #DC2626;
  --warn:   #D97706;

  /* 圆角纪律 */
  --r-pill: 999px;   /* 按钮 / 输入框 / 勋章胶囊 */
  --r-card: 8px;     /* 卡片 / 遮罩 */
  --r-none: 0;       /* 面板 / 栏 */

  /* 尺寸 */
  --h-topbar: 48px;
  --h-bottombar: 56px;
  --w-sidebar: 280px;   /* 桌面端窗口小可 240px */
  --gap: 12px;
}
```

## 二、整体布局（两端统一）

```
┌───────────────────────────────────────┬──────────────┐
│ 顶栏：logo + 状态 + 操作入口             │              │
├───────────────────────────────────────┤  右侧聊天栏   │
│                                       │  固定宽通栏到底│
│           视频画面（黑色 16:9）         │  ├ 头部观众数 │
│                                       │  ├ 消息流     │
│                                       │  └ 胶囊输入框 │
├───────────────────────────────────────┤              │
│ 底部控制条：开始/停止/复制/画质/声音     │              │
└───────────────────────────────────────┴──────────────┘
```

- **网页端**：首页是居中卡片（无侧栏）；主机/观众是「左视频 + 右侧栏」。
- **桌面端**：窗口 = 「左视频 + 右侧栏 + 顶栏 + 底栏」，自绘选源页是覆盖层。

---

## 三、聊天栏（重点）

- **位置**：右侧**固定宽 280px，从顶栏下沿通栏到底**（不是浮动卡片，浮动卡片是割裂根因）。
- **背景**：`#FFFFFF`，与视频区用 1px `--line` 分隔。
- **消息：无气泡平铺文字流**（直播弹幕惯例）：
  - 一行 = `[主播徽章] 昵称 正文`，基线对齐，无头像、无背景、无左右分栏。
  - 昵称 `--text-3`，正文 `--text-2`，主播徽章紫色小胶囊白字。
  - 行高 24px，hover 整行 `--bg-hover`。
- **输入区（底部固定）**：胶囊输入框 `--bg-input` + 紫色发送按钮；回车发送。
- **弹幕**：视频画面上从右往左滚动，固定轨道；关闭弹幕只关画面滚动，不影响侧栏消息流。

---

## 四、配色逻辑

1. 浅色暖灰 + 白面板，视频框保持黑（画面是唯一的大块深色，视觉焦点）。
2. **紫色只承担一种语义**：主按钮（开始共享/发送）、选中态、主播徽章、自己消息高亮。其余全灰阶。
3. 分区靠 1px `--line`，不靠阴影。

---

## 五、桌面端适配

- 与网页端同一套令牌、同一套布局，浅色 + 紫色品牌色。
- 窗口默认 1100×680，右侧聊天栏固定 240px。
- 自绘选源页：覆盖层卡片 `--bg-panel` + 1px 细线 + 6px 圆角，列表项 hover `--bg-hover`，选中态紫色描边。

---

## 六、圆角 / 线 / 阴影纪律

1. 胶囊 999px：按钮、输入框、勋章。
2. 6-8px：卡片、遮罩。
3. 直角 0：顶栏、底栏、侧栏、消息区。
4. 分区只用 1px `--line`，浅色下阴影可少量（`0 1px 2px rgba(0,0,0,.04)`），但以细线为主。
