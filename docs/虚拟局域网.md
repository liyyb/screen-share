# 虚拟局域网跨网共享（Radmin LAN / Tailscale / ZeroTier）

不用公网服务器、不用域名、不用 TURN。用组网工具把所有设备放进同一个**虚拟局域网**，屏幕共享就在这个虚拟局域网内 P2P 直连——这是「不同网看屏幕」最省事的做法。

## 原理

- 组网工具给每台设备分配一个虚拟局域网 IP（Radmin VPN 用 `26.x.x.x`，Tailscale 用 `100.x.x.x`，ZeroTier 用自定网段）。
- 主机在虚拟局域网内跑信令服务，观众通过主机的**虚拟 IP** 访问。
- WebRTC 在虚拟局域网内直接 P2P，延迟低，媒体不经过任何第三方服务器。

## 步骤

### 1. 组网

所有设备（主机 + 观众）装同一个组网工具，加入同一网络：

- **Tailscale**（推荐，免费、自动打洞、跨平台）
- **Radmin LAN / Radmin VPN**
- **ZeroTier**

在组网工具里记下**主机的虚拟 IP**（例如 `100.64.0.5` 或 `26.0.0.3`）。

### 2. 主机启动服务

```bash
HOST=0.0.0.0 PORT=3000 PUBLIC_ORIGIN=http://<主机的虚拟IP>:3000 node server/main.mjs
```

把 `<主机的虚拟IP>` 换成第 1 步记下的 IP。`PUBLIC_ORIGIN` 决定邀请链接的域名，务必填虚拟 IP，否则观众打不开。

> 双击 `启动服务.bat` 默认使用物理局域网 IP，方便同一网络的手机扫码。组网时在启动前显式设置 `PUBLIC_ORIGIN` 为指定虚拟 IP 的访问地址。也可设置 `PREFER_VIRTUAL_LAN=1`，让程序优先使用自动探测到的虚拟网卡。

### 3. 主机分享

主机浏览器打开 **`http://localhost:3000`**（必须是 localhost —— `getDisplayMedia` 抓屏需要安全上下文），点「开始共享」→ 选窗口 → 复制邀请链接。

### 4. 观众观看

观众（不同物理网络，但已加入同一虚拟局域网）打开邀请链接，或访问 `http://<主机的虚拟IP>:3000` 输入 6 位房间码。观众端只需 `RTCPeerConnection`，走普通 HTTP 即可，不需要安全上下文。

## 说明与排障

| 现象 | 排查 |
| --- | --- |
| 观众打不开链接 | `PUBLIC_ORIGIN` 没填主机的虚拟 IP；或组网工具未连通（先在两端 `ping` 对方虚拟 IP） |
| 主机点「开始共享」无反应 | 主机必须用 `localhost` 打开，不能用虚拟 IP 打开（否则非安全上下文无法抓屏） |
| 一直「正在连接」 | 组网工具的 P2P 未打通；确认两端互相 `ping` 通，且防火墙放行虚拟网卡 |
| 想确认虚拟 IP | 启动服务时看预检输出里的 `[提示] 虚拟局域网网卡`，或组网工具界面查看 |
